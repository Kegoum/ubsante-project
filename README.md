🏥 UBSANTE - Healthcare Management Platform
A full-stack healthcare management application designed to digitalize hospital administrative operations, patient management, pharmacy billing, and medical document workflows.

This project demonstrates practical experience in web application development, database design, healthcare information management, and enterprise software architecture.

📋 Project Summary
Healthcare facilities often rely on multiple disconnected systems for patient registration, billing, document management, and communication.

UB Santé centralizes these operations into a unified platform that enables healthcare staff to:

Manage patient information
Process pharmacy transactions
Generate medical documents and reports
Send notifications through email
Store and retrieve healthcare records efficiently
The objective was to improve operational efficiency while reducing manual administrative processes.

🚀 Installation
Clone Repository
  git clone https://github.com/Kegoum/ubsante-project.git
  cd ubsante-project
  
Configure Database
  Create a MySQL database and import: hopitalbd.sql
  Update database credentials in: hopitalconnexion/
  
Run Application
Deploy to:
  XAMPP  → htdocs
  WAMP   → www
  LAMP   → /var/www/html
  
Launch: http://localhost/ubsante-project
